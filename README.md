# GuardVPN releases

Signed Windows installers for **GuardVPN**, a personal, self-hosted WireGuard VPN app.

This repository contains **release files only** (installer, signature, `latest.json` for the in-app updater). The source code is private.

- **Install:** download `GuardVPN_<version>_x64-setup.exe` from [Releases](../../releases).
- **Update:** GuardVPN checks this repository itself (Settings → Updates) and only installs releases whose signature matches the public key built into the app.
